# Educational hurricane and occurrence-layer model

`src/loss.js` is pure, synchronous, deterministic and dependency-free. It does not fetch inputs or manage UI state. `simulatePortfolio({features, market, event, positions, capital})` accepts the ordered tract GeoJSON features used for `generateMarket(features, seed)`, that generated market, a single NOAA wind-swath GeoJSON FeatureCollection (or explicit `null` for no event), and USD investor capital. Never pass a failed or not-yet-loaded event as `null`: null means a genuine no-storm scenario and produces zero hazard loss.

```js
import {simulatePortfolio} from './loss.js';
const result = simulatePortfolio({features, market, event: ianSwaths, capital: 1000000,
  positions: [
    {index: 0, weight: 1, attachmentFraction: .02, limitFraction: .08, rateOnLine: .1},
    {index: 1, weight: 1, attachmentFraction: .02, limitFraction: .08, rateOnLine: .1}
  ]});
```

Each position selects a distinct zero-based cedent index; weights are finite nonnegative relative capital weights, fractions and ROL are decimals, not percentages. Attachment plus limit may not exceed 1. All inputs must be finite and nonnegative. Zero weights leave capital unallocated. Tracts and allocations must match in order and length. Returned `tracts` correspond to input order and contain `point` [longitude, latitude], `threshold` (0, 34, 50 or 64 knots), and `damageFactor`. Each returned position includes index, name, weight, units, exposure, grossLoss, budget, attachment, limit, principal, rateOnLine, share, cededLoss, investorLoss, premium and netReturn. Portfolio totals include `capital`, `totalPrincipal`, `unallocatedCapital`, `investorLoss`, `premium`, `netReturn`, and `returnOnPrincipal` (null when no principal). Dollars are unrounded floating-point values. No-selection yields zero principal and return-on-principal null.

For each tract, the representative location is the midpoint of its geometry's bounding box, matching the market generator; it can fall outside the tract. Test this point against actual Polygon/MultiPolygon NOAA swaths, including holes. Boundaries, including hole boundaries, count as covered. Use the greatest qualifying RADII threshold even with overlapping swath features. The fixed hypothetical damage factors for 0/34/50/64 knots are 0/1%/5%/20%, respectively. These are invented teaching assumptions, not observed damage, an engineering vulnerability curve, or a validated risk estimate. The static storm-lifetime NOAA maximum-potential extent is not a time-specific wind field or proof any location experienced the threshold. The historical Hurricane Ian swaths are from the NOAA NHC best-track GIS archive identified in README.md; source metadata in the data records the AL092022 event and 2022-09-22 18:00 through 2022-10-01 06:00 UTC interval. Generalized cartographic boundaries and a single point cannot establish parcel-level exposure, damage or claims. Present synthetic present-day exposure separately from the historical event. Only wind-like stylized loss is modeled, not surge, flood, expenses or actual insured losses.

For cedent c and tract t, let Uct be allocated fractional housing-proxy units, V = $300,000 per unit (assumed, not property values), and D(t) the zone factor. Units are not actual insured policies. Then exposure E(c) = sum(Uct) × V USD, and gross event loss G(c) = sum(Uct × V × D(t)) USD. This treats gross damage as an aggregate covered cedent loss: no individual policy terms, deductibles, sublimits, claims handling or underlying reinsurance are modeled. A(c) = attachmentFraction × E(c); L(c) = limitFraction × E(c). This attaches to aggregate cedent occurrence loss; it is an illustrative junior layer only if the selected terms describe one, not a representation of an actual contract.

Budget B(c) = capital × weight(c) / sum(weights), or 0 when the sum is 0. Principal P(c) = min(B(c), L(c)); unused capital is not redistributed. Layer ceded loss C(c) = min(L(c), max(0, G(c) − A(c))). Investor share S(c) = P(c)/L(c), or 0 for zero limit; investor loss = C(c) × S(c) ≤ P(c). Premium = P(c) × rateOnLine, assumed fully earned for this one period; net return = premium − investor loss. Portfolio outcomes sum positions; return on principal = net return / total principal. This is a single-event illustration, not an annual forecast. Premium is illustrative and ignores fees, costs, reinstatements, discounting, taxes and counterparty default. Principal is fully collateralized per position and total committed principal cannot exceed the input capital. Different cedents share the same event; geographic or cedent diversification does not guarantee protection or returns.

`classifyPoint(point, event)` exposes the swath classifier and `layerOutcome(loss, {attachment, limit, principal, rateOnLine})` exposes the dollar layer arithmetic. Run `npm test` for synthetic hand calculations and the checked-in Ian/Florida integration.
